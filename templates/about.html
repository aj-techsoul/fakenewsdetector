About This Project

AI-Powered Fake News Detection System

Project Overview

The FakeGuard AI is an intelligent news analysis system designed to help users identify potentially fake or misleading news articles. Using advanced machine learning algorithms and natural language processing techniques, the system analyzes the linguistic patterns, structure, and content of news articles to classify them as either Real or Fake with a high degree of accuracy.

This project demonstrates the practical application of NLP and supervised machine learning in combating misinformation — a critical challenge in today's digital information landscape.

How It Works

The system follows a standard NLP + ML pipeline:

  1. Text Preprocessing — Cleaning, lowercasing, removing stopwords and punctuation
  2. Stemming — Reducing words to their root form using Porter Stemmer
  3. TF-IDF Vectorization — Converting text to numerical features using Term Frequency-Inverse Document Frequency
  4. Classification — Using a trained PassiveAggressiveClassifier to predict the label
  5. Confidence Scoring — Computing prediction confidence from the decision function
  6. Explanation Generation — Analyzing linguistic patterns to produce human-readable explanations

Dataset

This project uses the ISOT Fake and Real News Dataset, a well-known benchmark dataset for fake news detection research. It contains over 40,000 news articles split evenly between real and fake news, sourced from legitimate news outlets and known misinformation websites.

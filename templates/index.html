Verification Engine Pipeline

How FakeGuard AI analyzes your article inputs inside the core ML cloud

01

Text Normalization

Emojis, special punctuation, and numbers are filtered. Clean text is normalized using Unicode NFC standard.

02

NLTK Lemmatization

Words are mapped to their dictionary root form using WordNet Lemmatizer to consolidate lexical features.

03

NLP Sentiment Audit

NLTK VADER calculates sentiment polarity to capture emotional charge (subjective phrasing is flagged).

04

Multimodel Selection

Text is mapped via TF-IDF (1-3 n-grams) and verified against the highest performing classifier (e.g. Linear SVM).

Frequently Asked Questions

Learn about the model pipeline and data processing guidelines

What classifiers does the training pipeline compare?
The platform trains 5 algorithms: Logistic Regression, Passive Aggressive, Linear SVM, Random Forest, and Naive Bayes. It ranks them based on F1-Score and selects the highest-scoring model.
How does clickbait highlight parsing function?
It searches for specific clickbait phrases, emotional trigger keywords, excess capitalizations, and multiple exclamation marks, returning exact string offsets for visualization.
Can I retrain the models dynamically?
Yes, system administrators can access the admin dashboard control panel to trigger model retraining asynchronously.
